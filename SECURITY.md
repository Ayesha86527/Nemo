# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately to the maintainers by opening a
**security advisory** on this repository (GitHub → Security → Advisories), or
email the address in the MAINTAINERS section of the README. Do **not** open a
public issue for security reports. We aim to respond within 72 hours.

## Security model

Nemo is a local-first desktop app. Understanding what it protects — and what it
deliberately does not — matters:

**What stays local**
- All application data (CV, jobs, roadmaps, chat history) lives in
  `~/.nemo/nemo.db` (SQLite) and `~/.nemo/cv/` on your machine.
- Nemo makes no telemetry, analytics, or account-network calls. The only
  outbound traffic is to the LLM endpoint **you** configure in Settings.
- **Voice**: voice input is transcribed by on-device faster-whisper and never
  leaves the machine. The only download is the Whisper model itself (once, from
  Hugging Face, to `~/.nemo/models/`). Spoken replies use your OS's built-in
  speech voices and make no network calls.

**Known, accepted trade-offs**
- Your LLM **API key is stored in plain text** in the local SQLite database
  (`~/.nemo/nemo.db`). This is the standard bring-your-own-key trade-off for
  local tools: any process running as your user can read it. If that is not
  acceptable, run Nemo against a local endpoint (e.g. Ollama) with a
  non-sensitive key.
- Everything you put in your CV, profile, and pasted job descriptions **is sent
  to your configured LLM endpoint** when you use AI features. Choose your
  provider accordingly; a local model keeps the loop fully on-device.

**Hardening in place**
- The local API binds to `127.0.0.1` on a random port and requires a
  per-launch token (`X-Nemo-Token`) generated by Electron, so other local
  processes or websites cannot read your data by probing the port.
- The renderer runs with `contextIsolation: true`, `nodeIntegration: false`,
  and a restrictive CSP (no remote scripts, styles, or fonts).
- The conversational agent treats model output as untrusted: mutations are
  whitelisted JSON actions applied by deterministic code. The agent **cannot**
  set API keys and can only switch the LLM endpoint between well-known
  providers — a prompt injected via a pasted job posting cannot redirect your
  CV to an attacker's server.
- Uploaded CVs are validated as real `.docx` files, size-capped at 10 MB, and
  written to a fixed path (no arbitrary file writes).

## Scope

The desktop app (this repository) is in scope. Vulnerabilities in third-party
LLM providers themselves are not.
