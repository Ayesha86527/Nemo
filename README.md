# Nemo - AI Career Co-Pilot

A **local-first, open-source** AI assistant that manages your CV, tracks job applications, analyses market gaps, and builds personalized learning roadmaps - all from your desktop, with your own LLM keys.

---

## Features

| Module | What it does |
|---|---|
| **CV Studio** | Upload your `.docx` CV, auto-extract skills / experience / projects, and edit structured content. The Nemo Agent can update your CV through natural conversation. |
| **Job Tracker** | Paste any job posting to get an instant role-match analysis + company research, tailored CV, and cover letter. Applications are tracked automatically with status, follow-up reminders, and preparation gates. |
| **Market Intelligence** | AI-powered gap analysis comparing your CV against market demand for your target role. Identifies skill gaps, market signals, and actionable recommendations. |
| **Learning Roadmap** | Personalized milestone-based learning plans grounded in your skill gaps. Checkable steps, progress tracking, and fully customizable through the Nemo Agent. |
| **Nemo Agent** | Conversational AI assistant that can modify your CV, change settings, generate roadmaps, run market intel, tailor CVs, write cover letters, and manage job applications - all through natural language or voice. |

## Architecture

```
nemo/
+-- frontend/          # Electron desktop app (React + TypeScript)
|   +-- src/
|       +-- main.ts    # Electron main process - spawns the Python sidecar
|       +-- preload.ts # Secure IPC bridge (contextIsolation)
|       +-- renderer/  # React UI (views, components, API client)
+-- backend/           # FastAPI Python backend
    +-- app/
        +-- agent/     # Nemo conversational agent (structured JSON actions)
        +-- cv/        # CV upload, extraction, content, and tailoring
        +-- jobs/      # Job tracker + gated preparation workflow
        +-- market/    # Market intelligence + gap analysis engine
        +-- roadmap/   # Learning roadmap generation
        +-- research/  # Company + role research pipeline
        +-- llm/       # OpenAI-compatible provider abstraction
        +-- db/        # SQLite models + migrations
```

**How it works:**
- Electron spawns the FastAPI backend as a sidecar process on app start.
- The backend auto-selects a free port and communicates it to the renderer via IPC.
- All data is stored locally in `~/.nemo/nemo.db` (SQLite) - nothing leaves your machine except LLM API calls.
- The Nemo Agent uses structured JSON actions to make deterministic mutations - the LLM never writes to the database directly.

**LLM compatibility:** Works with any OpenAI-compatible endpoint - Groq, DeepSeek, OpenRouter, Mistral, local Ollama, or any other provider that speaks the OpenAI chat completions API.

## Prerequisites

- **Node.js** >= 18
- **Python** >= 3.12
- An **OpenAI-compatible LLM endpoint** - e.g. [Groq](https://console.groq.com) (free tier), [DeepSeek](https://platform.deepseek.com), or local [Ollama](https://ollama.com)

## Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/<you>/nemo.git
cd nemo

# 2. Install the Python backend
cd backend
pip install -e .          # or: uv pip install -e .
cd ..

# 3. Install the Electron frontend
cd frontend
npm install
cd ..

# 4. Build and launch
cd frontend
npm run dev
```

On first launch:
1. Go to **Settings** and enter your LLM endpoint URL, API key, and model name.
2. Or open the **Nemo Agent** and say: *"Point my LLM at Groq"* - it will configure the endpoint automatically.

### Using Ollama (fully local, no API key)

```bash
ollama pull llama3.2
```
Then in Nemo **Settings**:
- Endpoint: `http://localhost:11434/v1`
- API Key: `ollama` (any non-empty string)
- Model: `llama3.2`

### Fully local voice (zero cost)

Voice runs **entirely on your machine** — there are no voice settings to configure:

- **Voice input** is transcribed on-device by [faster-whisper](https://github.com/SYSTRAN/faster-whisper);
  recordings never leave your machine and cost nothing. One-time setup:
  ```bash
  cd backend
  pip install -e ".[voice]"
  ```
  The Whisper model (~150 MB) downloads to `~/.nemo/models/` on first use,
  then everything is offline.
- **Spoken replies** — the Nemo chat has a "Speak replies" toggle and a 🔊
  button on each reply, using your operating system's built-in voices
  (no download, no network call).

## Data & Privacy

- All your data lives in `~/.nemo/nemo.db` on your machine.
- CV files are stored in `~/.nemo/cv/`.
- Tailored CVs and cover letters generated by the agent are saved to `~/Downloads/`.
- The only network calls Nemo makes are to your configured LLM endpoint — even the UI fonts are bundled locally.
- No telemetry, no analytics, no accounts required.
- See [SECURITY.md](SECURITY.md) for the full security model, including how your API key is stored and how the local API is protected.

---

## Principles

- **Local-first.** Your CV and job search never leave your machine except as prompts to the LLM endpoint *you* choose (a local Ollama model keeps everything on-device).
- **The model proposes, the code disposes.** The Nemo Agent emits whitelisted JSON actions that deterministic code applies — it never writes to the database, can't touch your API key, and can only switch the LLM endpoint between well-known providers.
- **No auto-apply.** Nemo helps you prepare fewer, better applications. It never submits anything for you or scrapes job boards.
